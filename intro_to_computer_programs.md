
## Introduction to Computers, Programs, and Python – Study Guide

### Computer Programming
**Definition:** The process of writing instructions (program/software/code) to tell a computer how to perform a specific action.

---

### Basic Concepts
- **What is an algorithm?**
  A set of step-by-step instructions for solving a problem.

- **What is source code (script file)?**
  Human-readable instructions written in a programming language.

- **What file extension do Python source code files have?**
  `.py`

---

### Software vs. Hardware
- **What’s the difference between software and hardware?**
  - *Hardware* is the physical components of a computer (e.g., CPU, RAM, monitor).
  - *Software* is the set of instructions that run on the hardware.

- **What is hardware?**
  The physical aspects of a computer (e.g., keyboard, motherboard).

- **Examples of input and output devices:**
  - *Input:* Keyboard, mouse
  - *Output:* Monitor, printer

- **CPU vs Memory vs Storage Devices:**
  - *CPU:* Executes instructions; brain of the computer
  - *Memory (RAM):* Temporarily stores data for CPU
  - *Storage:* Permanent data retention (e.g., SSD, HDD)

- **What is a motherboard?**
  A circuit board connecting all computer components.

- **What is a bus?**
  A communication system that transfers data between components.

- **What is cache?**
  Small, fast memory located inside or close to the CPU.

- **Why is RAM volatile?**
  Because it loses data when power is off.

- **What happens when you execute a program?**
  1. The OS locates the program on storage.
  2. Moves it into memory (RAM).
  3. CPU fetches and executes instructions from memory.

- **Multiprocessing vs. Multithreading:**
  - *Multiprocessing:* Multiple CPUs or cores working in parallel.
  - *Multithreading:* Multiple threads (tasks) within a single process executed concurrently.

- **How is CPU measured?**
  In gigahertz (GHz)

- **Examples of storage devices:**
  Hard drive, SSD, USB drive, CD/DVD

- **How are storage devices measured?**
  In bytes (KB, MB, GB, TB)

- **How do storage devices differ from memory?**
  Storage is non-volatile and slower; memory is volatile and faster.

- **Characteristics of storage devices:**
  Non-volatile, slower than RAM, long-term data retention

---

### Data Storage Units
- **Bits vs Bytes vs Megabytes vs Gigabytes vs Terabytes:**
  - 1 Byte = 8 Bits
  - 1 KB ≈ 1,000 Bytes
  - 1 MB ≈ 1,000 KB
  - 1 GB ≈ 1,000 MB
  - 1 TB ≈ 1,000 GB

---

### Communication Devices
- **What is a NIC (Network Interface Card)?**
  A hardware component that connects a computer to a network.

- **What is Wi-Fi?**
  Wireless networking technology enabling data transfer via radio waves.

---

### Software Types
- **Application vs. System Software:**
  - *Application:* Performs specific tasks (e.g., Word, Excel, Fortnite)
  - *System:* Manages hardware (e.g., Windows, macOS, Linux)

- **Examples:**
  - *Application:* Chrome, Photoshop
  - *System:* Windows, Linux, macOS

- **What is an Operating System?**
  A program that manages computer hardware and software resources.

- **Examples of Operating Systems:**
  Windows, macOS, Linux

- **Tasks of an OS:**
  - Manage memory
  - Control input/output devices
  - Manage files
  - Schedule tasks

---

### Software Development Life Cycle (SDLC)
- **Definition:**
  A process for developing software in a structured way.

- **Why is it necessary?**
  Ensures systematic, efficient, and error-minimized development.

- **Steps of SDLC:**
  1. Requirements Analysis
  2. Design
  3. Implementation
  4. Testing
  5. Deployment
  6. Maintenance

---

### Programming Languages
- **What is a programming language?**
  A formal language for writing software instructions.

- **Examples:**
  Python, Java, C++, C#, JavaScript

- **Low-level vs. High-level Languages:**
  - *Low-level:* Machine code, Assembly (machine-dependent)
  - *High-level:* Python, Java (platform-independent)

- **Machine-dependent vs. Platform-independent:**
  - *Machine-dependent:* Runs on specific hardware (Assembly)
  - *Platform-independent:* Can run on different systems (Python)

---

### Errors in Programming
- **Syntax Errors:** Found by the compiler/interpreter before execution
- **Run-time Errors:** Occur while the program is running
- **Logic Errors:** Incorrect results due to faulty logic

---

### Integrated Development Environment (IDE)
- **Definition:**
  Software for writing, testing, and debugging code.

- **Components of an IDE:**
  Editor, compiler/interpreter, debugger

- **Examples:**
  IDLE, PyCharm, VSCode

- **Modes in Python:**
  - *Script mode:* Running code from a file
  - *Interactive mode:* Running code from `>>>` prompt

---

### Translating Code to Machine Language
- **What is machine language?**
  Binary instructions executed by the CPU.

- **Assembler vs Compiler vs Interpreter:**
  - *Assembler:* Translates assembly to machine code
  - *Compiler:* Translates entire high-level code to machine code before execution
  - *Interpreter:* Translates and runs code line by line

- **What does Python use?**
  An interpreter
