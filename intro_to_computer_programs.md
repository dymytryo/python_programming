
## Introduction to Python Programming – Study Guide

### 1.1 Introduction
**Definition:** The process of writing instructions (program/software/code) to tell a computer how to perform a specific action.

---

### 1.2 What Is a Computer?
- A computer includes both hardware and software.

---

### 1.2.1 Central Processing Unit
- **CPU:** Executes instructions; brain of the computer
- **What is a motherboard?** A circuit board connecting all computer components.
- **What is a bus?** A communication system that transfers data between components.
- **What is cache?** Small, fast memory located inside or close to the CPU.
- **How is CPU measured?** In gigahertz (GHz)
- **Multiprocessing vs. Multithreading:**
  - *Multiprocessing:* Multiple CPUs or cores working in parallel.
  - *Multithreading:* Multiple threads (tasks) within a single process executed concurrently.

---

### 1.2.2 Bits and Bytes
- **Bits vs Bytes vs Megabytes vs Gigabytes vs Terabytes:**
  - 1 Byte = 8 Bits
  - 1 KB ≈ 1,000 Bytes
  - 1 MB ≈ 1,000 KB
  - 1 GB ≈ 1,000 MB
  - 1 TB ≈ 1,000 GB

---

### 1.2.3 Memory
- **Memory (RAM):** Temporarily stores data for CPU
- **Why is RAM volatile?** Because it loses data when power is off.
- **What happens when you execute a program?**
  1. The OS locates the program on storage.
  2. Moves it into memory (RAM).
  3. CPU fetches and executes instructions from memory.

---

### 1.2.4 Storage Devices
- **Examples of storage devices:** Hard drive, SSD, USB drive, CD/DVD
- **How are storage devices measured?** In bytes (KB, MB, GB, TB)
- **How do storage devices differ from memory?** Storage is non-volatile and slower; memory is volatile and faster.
- **Characteristics of storage devices:** Non-volatile, slower than RAM, long-term data retention

---

### 1.2.5 Input and Output Devices
- **Examples of input and output devices:**
  - *Input:* Keyboard, mouse
  - *Output:* Monitor, printer

---

### 1.2.6 Communication Devices
- **What is a NIC (Network Interface Card)?** A hardware component that connects a computer to a network.
- **What is Wi-Fi?** Wireless networking technology enabling data transfer via radio waves.

---

### 1.3 Programming Languages
- **What is a programming language?** A formal language for writing software instructions.
- **Examples:** Python, Java, C++, C#, JavaScript
- **Low-level vs. High-level Languages:**
  - *Low-level:* Machine code, Assembly (machine-dependent)
  - *High-level:* Python, Java (platform-independent)
- **Machine-dependent vs. Platform-independent:**
  - *Machine-dependent:* Runs on specific hardware (Assembly)
  - *Platform-independent:* Can run on different systems (Python)

---

### 1.4 Operating Systems
- **What is an Operating System?** A program that manages computer hardware and software resources.
- **Examples of Operating Systems:** Windows, macOS, Linux
- **Tasks of an OS:**
  - Manage memory
  - Control input/output devices
  - Manage files
  - Schedule tasks

---

### 1.5 The History of Python
- Created by Guido van Rossum in 1990 in the Netherlands.
- Open-source and used by organizations like NASA, NYSE, and Google.
- Python 3 is not backward compatible with Python 2.

---

### 1.6 Getting Started with Python
- **What is source code (script file)?** Human-readable instructions written in a programming language.
- **What file extension do Python source code files have?** `.py`
- **Modes in Python:**
  - *Script mode:* Running code from a file
  - *Interactive mode:* Running code from `>>>` prompt
- **What is an IDE?** Software for writing, testing, and debugging code.
- **Components of an IDE:** Editor, compiler/interpreter, debugger
- **Examples:** IDLE, PyCharm, VSCode

---

### 1.7 Programming Style and Documentation
- Use meaningful variable names.
- Indent consistently.
- Comment code to describe logic and steps.

---

### 1.8 Programming Errors
- **Syntax Errors:** Found by the compiler/interpreter before execution
- **Run-time Errors:** Occur while the program is running
- **Logic Errors:** Incorrect results due to faulty logic

---

### 1.9 Translating Code to Machine Language
- **What is machine language?** Binary instructions executed by the CPU.
- **Assembler vs Compiler vs Interpreter:**
  - *Assembler:* Translates assembly to machine code
  - *Compiler:* Translates entire high-level code to machine code before execution
  - *Interpreter:* Translates and runs code line by line
- **What does Python use?** An interpreter

---

### Software Development Life Cycle (SDLC)
- **Definition:** A process for developing software in a structured way.
- **Why is it necessary?** Ensures systematic, efficient, and error-minimized development.
- **Steps of SDLC:**
  1. Requirements Analysis
  2. Design
  3. Implementation
  4. Testing
  5. Deployment
  6. Maintenance

---

### Basic Concepts
- **What is an algorithm?** A set of step-by-step instructions for solving a problem.
